Module 1 · Why SAEs exist at all

The superposition hypothesis, illustrated in 2D — the entire motivation in one picture.

A transformer has a residual stream of finite width d_model (Gemma-2-2B: 2304). It needs to represent more concepts than dimensions. How? Two options:

A · Without superposition: orthogonal basis

d=2 dimensions, 2 features.
No interference. Each axis = one concept.
Limit: ≤ d features total.

B · With superposition: 5 features in 2D

d=2 dimensions, 5 features.
Non-orthogonal → mild interference between adjacent features.
Wins if features are sparse (only 1 active at a time).

The bet that makes it work

If only one feature is "on" at any moment, the activation lies near a single direction. Decoding back to "which feature is active" is easy despite the non-orthogonal directions — the off-axis features contribute small noise but not enough to confuse the decoder. The model trades a little interference for a lot of capacity.

The SAE's job: given an activation vector, recover which of the over-complete set of directions the model is using. That's why d_sae ≫ d_model (this repo: 18,432 vs 2304, an 8× expansion). The SAE provides the wider canvas the model needed but couldn't have inside itself.

Empirical reality (Anthropic Toy Models, 2022)

As features get sparser, the model packs more and more of them into the same d_model dimensions, organizing them into regular polygons (digons, triangles, pentagons, ...). This is not a metaphor — they literally observed this geometry in toy models. Real transformers are believed to do the same, just messier.
